# Projeto-ICD
Trabalho académico, cujo objetivo assenta na perceção da IA no mercado de trabalho por tempo e delimitações territoriais. Para isso, é mostrado, ao longo desta aplicação, vários meios interativos que permitem realizar uma análise a partir de gráficos, tabelas e mapas.
A pasta está zipada, e dentro dela tem 4 pastas (apresentacao_ICD; artigo_ICD; dashboard_ICD e notebooks_ICD) onde tem todos os documentos que utilizámos para a realização deste projeto.
